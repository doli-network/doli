# INC-I-308 — impact matrix (run 732)

Change: every one of the 14 `ADMIN_METHODS` needs `Authorization: Bearer <token>` from every source address
(M1 `5cc7e23c`); the node always has a token (env `DOLI_RPC_ADMIN_TOKEN` / config if ≥ 32 chars, else
`<data_dir>/rpc-admin.token`, 0600, 64 hex, created by the node). Handler fixes for P1-004/-005/-007/-008 (M2).
Operator tools send the token on admin calls only (M3). Gauntlet rows GS-056/057/058/061 (M4 `99f1ddf9`).
No consensus rule, block content, protocol version or activation height changes. P2P is untouched.
